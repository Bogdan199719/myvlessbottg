# Security policy

## Reporting a vulnerability

Не создавайте публичный Issue для уязвимости и не прикладывайте токены, пароли, `.env`, базу данных или subscription-ссылки. Откройте приватный security advisory в GitHub для этого репозитория либо свяжитесь с владельцем репозитория напрямую.

В сообщении укажите:

- краткое описание и возможное влияние;
- шаги воспроизведения без реальных пользовательских данных;
- затронутую версию или commit SHA;
- возможный безопасный способ исправления, если он известен.

После подтверждения будет согласован срок исправления и публичного раскрытия.

## Operational guidance

- храните `.env` с правами `600`;
- не публикуйте `users.db`, backup-файлы и логи с персональными данными;
- оставляйте `ENABLE_WEB_UPDATES=false`, если нет осознанной необходимости в этой функции;
- размещайте приложение только за HTTPS reverse proxy.
