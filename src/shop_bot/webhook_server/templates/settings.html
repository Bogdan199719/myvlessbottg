🛡️ Лимит IP и подозрительная активность

Активные IP считаются по всей подписке. Сначала пользователь получает предупреждение, а ограничение включается после льготного периода или досрочно администратором.

Контроль {{ 'Включён' if settings.ip_limit_enabled == 'true' else 'Выключен' }}
Разрешено IP {{ settings.ip_limit_max_ips or '10' }}
Событий в журнале {{ ip_limit_events|length }}
Активных ограничений {{ ip_limit_enforced_count }}
Применяется к существующим клиентам и автоматически учитывается на новых хостах.
В часах. До окончания этого времени подключения не ограничиваются.
Учитываются только IP, замеченные панелью за последние минуты. Рекомендуется 10.

Проверка выполняется каждые 5 минут. Превышение подтверждается двумя проверками подряд. Одинаковый внешний IP на разных VPN-серверах считается один раз; сырые IP бот не сохраняет и не пишет в журнал. После предупреждения и льготного периода заданный лимит 3x-ui выставляется на всех конфигурациях пользователя. Сам 3x-ui применяет его отдельно на каждой конфигурации, поэтому это защита от раздачи подписки, а не точный счётчик физических устройств.
